# حزمة التراجع لـ Qatar4u TV

هذه الحزمة تعيد التابلت (Galaxy Tab S6، موديل SM-T865) إلى ما كان عليه قبل تركيب Qatar4u TV.

## محتوى الحزمة

| الملف | ما فيه |
|---|---|
| `Changes_Log.csv` | كل تغيير حدث على التابلت، مع أمر التراجع عنه |
| `Installed_Packages.txt` | قائمة التطبيقات كما كانت قبل أي تغيير |
| `Backup_Instructions.md` | كيف تأخذ نسخة احتياطية قبل التراجع |
| `Restore_Instructions.md` | خطوات الاسترجاع بالترتيب |
| `ADB_Recovery_Commands.txt` | أوامر الاسترجاع جاهزة للنسخ |

## ما الذي تغيّر على التابلت

- تعطيل 44 تطبيقاً من تطبيقات سامسونج (Bixby، والإعلانات وجمع البيانات، وملصقات AR، ومركز الألعاب، وغيرها). التعطيل لا يحذف التطبيق، ويمكن تفعيله من جديد في أي وقت.
- تقليل سرعة الحركات إلى النصف.
- إبقاء الشاشة مضاءة أثناء الشحن.
- تركيب واجهة Qatar4u TV Home ثم Qatar4u TV، وجعل الواجهة الشاشة الرئيسية.

لم يُحذف أي تطبيق من النظام، ولم يُستخدم Root، ولم يُعدَّل قسم النظام.

## قبل أن تبدأ

لا تنفّذ أوامر الاسترجاع قبل أن تنظر في حالة الجهاز. شغّل هذين الأمرين أولاً وقارن النتيجة بما في `Changes_Log.csv`:

```
adb shell pm list packages -d
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

ثم اتبع `Restore_Instructions.md`.
